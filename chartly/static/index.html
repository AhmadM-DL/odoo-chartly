Chartly — Natural Language Charting for Odoo

Chartly is an Odoo utility module that empowers users to generate data charts and visualizations using natural language prompts. It helps transform Odoo data into intuitive visual insights with minimal setup.

🚀 Key Features

  • 🗣️ Generate charts from natural language descriptions
  • 📊 Supports multiple chart types
  • 📈 Helps users explore data with AI-assisted queries

📦 Installation

  1. Clone the repository into your Odoo addons directory
  2. Add the path to your Odoo `addons_path`
  3. Install dependencies with:
    4. pip3 install -r requirements.txt
  4. Restart the Odoo server, update apps list, search for Chartly and install
